Advanced: verification, approval policy & separate admin setup

Setup generates the private Ed25519 approval key locally and proves possession automatically. Only its public key and signatures reach Infraveil. The downloaded bootstrap is bound to the selected server, expires after five minutes, and can be used once. Launcher installation remains locked until this verification succeeds, including in the interactive demo.

Basic setup keeps the approval console and launcher on the same Linux server. It is convenient but shares that machine's security boundary. For the strongest independent release veto, use the separate admin-workstation arrangement and its existing key instead. A fresh console must not replace a workspace's previously registered key.

Manual review retains your veto. Allowlist is available from the console. Auto approval is deliberately opt-in and requires typing AUTO because it signs all requested changes and gives up that practical veto while enabled.

The console manages its isolated folder, hash-locked dependencies, scoped approval token, and signed launcher checks. Existing workloads are never stopped solely because enrollment is incomplete.
