Export Data

Export workspace data

Download retained workspace configuration, runtime reports, logs, traffic records, and action history as a sanitized JSON bundle. Review the included data and redactions below.

Included
Workspace and runtime data

Agents, launcher hosts, status payloads, operations payloads, console logs, request trace, control trace, security events, pipeline logs, remediation state, command receipts, telemetry state, runtime contract metadata, and optional package file metadata with SHA-256 hashes.

Redacted
Credential material

Password hashes, TOTP seeds, machine tokens, encryption keys, API keys, webhook secrets, private keys, CSRF values, passkey credential material, processor references, and implementation source are not exported as usable secrets or product internals.

Format
Single JSON bundle

The export is designed for portability, support escalation, compliance review, customer inspection, and account exit. Runtime contracts and optional package files are represented by metadata and hashes instead of private application source.
